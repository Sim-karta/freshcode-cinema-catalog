# Каталог фільмів

Початковий каркас програми на React і Vite, організований Feature-Sliced ​​Design (FSD).

## Запуск

``` bash
npm install
npm run dev
```

## Структура `src`

- `app/` - ініціалізація програми, провайдери, маршрутизація та глобальні стилі.
- `pages/` - сторінки програми.
- `widgets/` – великі композиційні блоки інтерфейсу.
- `features/` - дії користувача та сценарії.
- `entities/` - бізнес-сутності та пов'язані з ними дані та інтерфейс.
- `shared/` - компоненти, що перевикористовуються, утиліти, конфігурація та ресурси.

Каталоги залишені порожніми навмисно: `.gitkeep` дозволяє Git зберігати їх у репозиторії. Публічні сегменти API і реалізація функціональності будуть додаватися в міру розробки.
